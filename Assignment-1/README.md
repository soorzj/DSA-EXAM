# Assignment Questions
1. Write a program to check for matching brackets in an expression using stacks(array).
2. Implement two stacks using a single one dimensional array. 
3. Write a program to do Decimal to binary conversion using stack (array). 
4. Write a program to implement the priority Queue ADT using linked list with all operations. 
5. Write an program to implement a normal queue using stacks (linked list). 
6. Design and implement an efficient Multilevel Telephone Directory System using a custom 
Linked List structure in C. To optimize search times, the directory must maintain a primary sorted 
linked list of Index Nodes (representing the letters A–Z). Each Index Node points to a separate, singly 
linked list of Contact Nodes (storing Name, Phone Number, and Email) starting with that letter.
Your implementation must be dynamic and handle the following operations:
    1. Insertion: Insert a new contact. The program must first find or create the appropriate letter index 
    node. The contact must then be inserted into the sub-list. Duplicate phone numbers are strictly 
    prohibited.
    2. Deletion: Delete a contact by name. If the deleted contact was the only person under that letter, 
    the corresponding Index Node must also be freed from memory.
    3. Search: Given a search string (e.g., "Joh"), display all contacts whose names start with that prefix.
